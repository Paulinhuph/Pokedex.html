- Uma Pokédex interativa desenvolvida com HTML, CSS e JavaScript, que consome dados de Pokémon e exibe informações básicas diretamente na interface.
- O projeto simula uma Pokédex clássica, permitindo navegar entre Pokémon ou buscar diretamente pelo nome ou número.

## 🚀 Funcionalidades

- Exibição de Pokémon na tela da Pokédex
- Busca por nome ou número do Pokémon
- Navegação entre Pokémon usando os botões Next e Prev
- Interface inspirada na Pokédex clássica dos jogos Pokémon

## 🧠 Tecnologias utilizadas
- HTML5 — estrutura da aplicação
- CSS3 — estilização da interface
- JavaScript — lógica da aplicação e manipulação de dados
- PokéAPI — obtenção das informações dos Pokémon

## 📦 Como executar o projeto
Clone o repositório:
git clone https://github.com/Paulinhuph/pokedex.git
Acesse a pasta do projeto:
cd pokedex
Abra o arquivo index.html no navegador.
Não é necessário instalar dependências.

## 🔎 Como usar

- Digite o nome ou número do Pokémon no campo de busca

- Pressione Enter ou utilize os botões de navegação

- Use Next ou Prev para navegar entre os Pokémon

## 📚 Objetivo do projeto

- Este projeto foi desenvolvido com foco em prática de desenvolvimento front-end, especialmente:
- Manipulação do DOM
- Consumo de API
- Organização de lógica em JavaScript
- Estruturação de interface com HTML e CSS
